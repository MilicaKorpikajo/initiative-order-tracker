# Class icons

These 17 icons are the Gloomhaven (1st edition) class icons from the **Gloomhaven Creator Pack**, which Isaac Childres (Cephalofair Games) shared for community use in the BoardGameGeek thread ["Files for creation"](https://boardgamegeek.com/thread/1733586/files-for-creation). They were exported from `Icon Pack/Class Icons and Augments.pdf` as 96 × 96 px transparent PNGs, cropped to the icon with no other changes. The app colours them with CSS masks.
